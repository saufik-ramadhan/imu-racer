# Asset credits

All artwork in `assets/` comes from [OpenGameArt.org](https://opengameart.org).
Two of the three pieces are CC-BY 3.0, which **requires** attribution wherever
the work is redistributed — including the built game, not only this repository.
The attribution below is also shown on the game's title screen.

## Car — Racer

- **Source:** https://opengameart.org/content/car-racer
- **Author:** Bahi
- **Licence:** [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/)
- **File:** `cars_racer.svg`
- **Changes made:** rasterised at load time, split into four separate sprites on
  transparent column gaps, and each sprite cropped to its bounding box.

## Toon Road Texture

- **Source:** https://opengameart.org/content/toon-road-texture
- **Author:** da_st — https://www.davidstenfors.com
- **Licence:** [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/)
- **File:** `Toon Road Texture_0.png`
- **Attribution notice from the author:** *"Please provide a link to my website
  (www.davidstenfors.com)."*
- **Changes made:** rotated 90° at load time so the road runs vertically, and

## Simple Explosion

## If you fork this

CC-BY 3.0 asks for three things: credit the author, link the licence, and
indicate that changes were made. Keeping `docs/CREDITS.md` and the title-screen
credit line intact satisfies all three. If you strip the credits out of the UI,
you also need to remove the CC-BY artwork.

The project's own code is MIT licensed, which is a separate matter — see
[`LICENSE`](../LICENSE).
